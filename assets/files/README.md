# 공개 파일 보관 폴더

이 폴더에 실제 CV PDF, 논문 PDF, 발표자료를 넣을 수 있습니다.
첨부된 가짜 논문 PDF는 없습니다. 파일을 넣기 전에는 해당 링크를 빈 문자열로 유지하세요.

- CV 예: `assets/files/cv.pdf` → `data.js`의 `profile.cvUrl: "./assets/files/cv.pdf"`
- 논문 예: `assets/files/paper-2026.pdf` → 논문의 `links.pdf: "./assets/files/paper-2026.pdf"`
- 발표자료 예: `assets/files/slides.pdf` → 논문의 `links.slides: "./assets/files/slides.pdf"`

파일명은 영문 소문자, 숫자, 하이픈을 권장합니다. 대소문자를 정확히 맞추세요.
공개 권한이 있는 파일만 올리세요. 이 폴더의 파일은 GitHub Pages에서 공개됩니다.
