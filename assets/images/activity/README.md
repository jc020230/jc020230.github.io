# 활동 사진 출처

사용자 제공 `이력서.hwpx`에서 추출한 사진입니다. 홈페이지용으로 WebP 변환 및 크기 조정만 적용했습니다. 원본 이력서는 공개 저장소에 포함하지 않습니다.

`dcase-presentation.webp`는 [CAU ET Lab 사진 페이지](https://ikwak2.github.io/photos/index.html)의 [DCASE 발표 사진](https://ikwak2.github.io/photos/dcase_kim.jpg)을 사용합니다. 사용자 요청에 따라 **CAU 팀 발표**로 표시합니다. 류정찬 개인의 직접 발표라고 표시하지 않습니다.

사진의 한·영 설명·행사별 묶음·출처 링크는 `assets/js/data.js`의 `gallery`에서 관리합니다.
